## 🍕 Featured Projects

### Level 3: Oasis Pizza — Full-Stack Pizza Delivery Application
Located under: [`WebDev-L3-PizzaDelivery/`](./WebDev-L3-PizzaDelivery/)

A production-grade, responsive full-stack pizza delivery web application built with:
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **Backend**: Node.js, Express, TypeScript, Zod, Bcrypt.js, JsonWebToken, Helmet.
- **Database**: MongoDB & Mongoose.
- **Payment Gateway**: Razorpay Test Mode with server-side HMAC-SHA256 cryptographic verification.
- **Background Jobs**: node-cron for automated inventory monitoring and low-stock email alerts.
- **Testing**: Vitest & Supertest with 19 passing automated integration tests.
