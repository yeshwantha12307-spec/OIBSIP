# Oasis Pizza — Application Screenshots & UI Showcase

This directory contains visual captures demonstrating the complete user experience, customer checkout flow, custom pizza builder, and administrator management portal.

## Recommended Screenshots to Capture

   - Hero section featuring bold typography, 450°C oven highlights, 4-pillar benefits, and signature chef picks.
2. **`02_craft_menu.png`**:
